# TexiolDexk Mobile v2.1.0

- When an Internet Device ID belongs to a Windows host on the same Wi-Fi, Android validates and probes the host's private LAN addresses using native `HttpURLConnection` and then opens the proven direct-LAN controller route.
- The fallback accepts only literal private/CGNAT IPv4 addresses on port 45911.
- The one-time PIN and visible host approval remain mandatory.
- WebRTC supports the Server's complete ICE configuration, optional TURN, ICE restart and privacy-safe diagnostics.
- Failed and cancelled attempts are closed immediately so they do not remain pending on the host.
